# MiniBlog API

API RESTful para la gestión de autores y publicaciones de un blog, desarrollada con Node.js, Express y PostgreSQL, desplegada en Railway y documentada con OpenAPI 3.0 / Swagger.

---

## Enlaces del Proyecto

- **API en Producción (Railway):** [https://apiminiblog-production.up.railway.app](https://apiminiblog-production.up.railway.app)
- **Documentación Interactiva (Swagger UI):** [https://apiminiblog-production.up.railway.app/api-docs](https://apiminiblog-production.up.railway.app/api-docs)

---

## Tecnologías Utilizadas

- **Node.js** & **Express**
- **PostgreSQL** (Driver `pg`)
- **Jest** & **Supertest** (Pruebas de integración)
- **OpenAPI 3.0** & **Swagger UI** (Documentación)
- **Railway** (Despliegue e infraestructura DB)

---
